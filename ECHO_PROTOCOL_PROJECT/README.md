# ECHO PROTOCOL: Survival Horror
**Developed by Rayyan the Dev**

## Project Structure
- `Scripts/`: Gameplay logic (GDScript).
- `Scenes/`: Level design and UI scenes.
- `Assets/`: 3D models, textures, and sound files.
- `Shaders/`: Custom AAA-quality visuals.
- `UI/`: Main menu, settings, and HUD.
- `Dialogue/`: Voice scripts and subtitles.
- `Audio/`: Dynamic soundscape.
- `Documentation/`: Build instructions.
